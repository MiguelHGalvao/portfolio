## Visão Geral

Este repositório contém a versão completa do meu **portfólio profissional**, estruturado para apresentar minha atuação na união entre **Desenvolvimento de Software (Python)**, **Inteligência Artificial (LLMs)** e **Business Intelligence & Análise de Dados**.

O projeto prioriza:
- **Design Editorial & Minimalista:** Inspirado em interfaces modernas e publicações de negócios contemporâneas.
- **Transparência Técnica:** Apresentação real de competências e estudos de caso práticos com foco em problema x solução.
- **Performance e Acessibilidade:** Carregamento instantâneo, código modular e responsividade integral para qualquer dispositivo.

---

## Funcionalidades e Diferenciais

- **Terminal Interativo (CLI):** Na seção principal, um widget simula um terminal Zsh interativo que permite navegar por comandos (`perfil.json`, `stack.py`, `objetivo.sh`).
- **Arquitetura Bento Grid:** Organização modular na seção *Sobre Mim*, destacando trajetória, mentalidade de produto e princípios que orientam o trabalho.
- **Filtro Dinâmico de Projetos:** Filtragem em tempo real entre categorias (*Todos*, *Python & IA*, *Dados & Analytics*, *Web & Games*).
- **Modais de Estudo de Caso:** Cada projeto possui uma tela de detalhes aprofundando o **Problema de Negócio**, a **Solução Desenvolvida**, as tecnologias aplicadas e links para o código-fonte.
- **Ação Direta de Contato:** Botão inteligente com cópia de e-mail em um clique e links integrados para redes profissionais.

## Como Executar Localmente

O projeto não exige instalação de gerenciadores de pacotes ou servidores complexos:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/MiguelHGalvao/portfolio.git
   cd portfolio
   ```

2. **Abra o arquivo diretamente:**
   - Dê um duplo clique no arquivo `index.html`, **ou**
   - Inicie um servidor local leve com Python:
     ```bash
     python -m http.server 3000
     ```
   - Acesse no navegador: `http://localhost:3000`

## Deploy e Publicação

### Publicação via GitHub Pages
1. Acesse o repositório no GitHub e vá em **Settings** > **Pages**.
2. Em **Source**, selecione a branch `main` e a pasta `/ (root)`.
3. Clique em **Save**. O site estará disponível em instantes no endereço:
   `https://miguelhgalvao.github.io/portfolio/`

### Publicação via Vercel
1. Conecte sua conta do GitHub na plataforma da Vercel.
2. Importe o repositório `portfolio` e confirme o deploy com as configurações padrão.
