# Portfólio Pessoal — Miguel Galvão

Site de portfólio profissional desenvolvido com foco em código limpo, design editorial minimalista e responsividade completa.

## 🎨 Identidade Visual
- **Fundo / Grafite Escuro:** `#0B0D0F` e `#17191C`
- **Tipografia / Off-White:** `#F2F0E9`
- **Destaque / Âmbar:** `#C18B42`
- **Fontes:** Plus Jakarta Sans & JetBrains Mono

## 🚀 Como Visualizar Localmente
Basta dar dois cliques no arquivo `index.html` ou abri-lo em qualquer navegador moderno.

Você também pode utilizar uma extensão como **Live Server** no VS Code ou rodar via terminal:
```bash
# Na pasta frontend:
npx serve .
# ou com Python:
python -m http.server 3000
```

## 🌐 Como Publicar Gratuitamente no Ar

### Opção 1: GitHub Pages (Sem complicação)
1. Crie um repositório no seu GitHub chamado `portfolio` (ou `miguel-galvao`).
2. Suba o arquivo `index.html`.
3. Vá em **Settings > Pages** no GitHub.
4. Em **Branch**, selecione `main` e clique em **Save**.
5. Seu site estará no ar em poucos segundos em: `https://seu-usuario.github.io/portfolio/`.

### Opção 2: Vercel (Recomendado para domínio próprio)
1. Conecte sua conta do GitHub na [Vercel](https://vercel.com).
2. Selecione o repositório e clique em **Deploy**.
